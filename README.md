# Later — Your Ultimate Read-It-Later Companion

Later is an Android read-it-later app built to make discovering, saving, organizing, and reading articles easier.

Inspired by the need for a better personal reading experience, Later brings your saved reading into one place.

## Features

- **Discover:** Explore articles from a range of publications and topics.
- **Save for later:** Keep interesting articles in your personal library.
- **Offline reading:** Save supported articles for reading without an internet connection.
- **Organize:** Manage your reading list, favorites, and archive.
- **Reading experience:** Enjoy a clean, dark interface designed for comfortable reading.
- **Personal library:** Keep track of articles you want to revisit.

## Built with

- Android
- Kotlin
- Jetpack Compose

## Project status

Later is an ongoing personal project. Features and implementation may evolve as development continues.
